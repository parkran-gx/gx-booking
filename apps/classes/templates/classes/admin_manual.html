② 월별 수강등록 운영 방법

1 등록기간 생성

수강등록 관리 → 새 등록기간 생성에서 수업, 연도/월, 정원, 우선접수 기간, 일반접수 기간을 설정합니다.

2 우선접수 대상자 지정

등록기간 상세 페이지에서 우선접수 관리 버튼을 눌러 기존 수강생을 수업별로 직접 지정합니다. 지정된 회원은 우선접수 기간에만 신청 가능합니다.

3 상태 관리

접수 기간이 지나면 상태 갱신 버튼으로 자동 전환됩니다. 수동으로 변경할 경우 상태 드롭다운에서 직접 선택합니다.
준비중 → 우선접수 → 일반접수 → 마감 → 종료

4 명단 내보내기

등록기간 상세에서 다운로드 버튼으로 Excel / PDF / CSV 형식으로 명단을 내보냅니다. 관리사무소 버튼으로 복사용 텍스트를 생성하여 카카오톡 등으로 전송합니다.

③ 수업 일정 관리

캘린더 → 일정 등록에서 수업 시작일·종료일·반복 요일을 설정하면 해당 기간의 모든 수업 회차가 자동 생성됩니다.

반복 유형

주 1회 — 매주 특정 요일 하나 (예: 매주 목요일)
주 2회 — 매주 두 요일 (예: 매주 월·목)
주 3회 — 매주 세 요일
직접 입력 — 날짜를 쉼표로 직접 입력 (예: 2026-06-03,2026-06-10)

이전 서식 불러오기 기능으로 지난 달 일정을 불러와 날짜만 수정하면 빠르게 등록할 수 있습니다.

개별 수업 회차를 변경할 경우 캘린더에서 수업을 클릭하여 날짜 변경 / 휴강 / 대강 강사 지정이 가능합니다.

④ 회원 관리

회원 관리 페이지에서 가입한 회원의 승인·등급 변경·삭제를 처리합니다.

회원 등급

슈퍼관리자모든 단지·수업·회원 관리 가능 (강사 계정)
단지관리자담당 단지 내 모든 관리 기능 사용 가능
등록회원수강 등록 및 예약이 가능한 승인된 입주민
미등록회원가입했으나 아직 승인 전인 회원

새 회원이 가입하면 미등록회원으로 표시됩니다. 입주민 확인 후 승인 버튼을 눌러 등록회원으로 변경해 주세요.

⑤ 출석 체크

캘린더에서 해당 날짜의 수업을 클릭하면 출석 체크 페이지로 이동합니다.

출석 수업에 정상 참석
결석 수업에 불참
보강 다른 날짜에 보강 수업 참석

출석 체크 후 출석부 PDF 버튼으로 출석부를 출력하거나 저장할 수 있습니다.

⑥ 관리사무소 연동

수강 등록 명단을 관리사무소에 제출해야 할 때 수강등록 관리에서 해당 등록기간을 선택 후 관리사무소 버튼을 클릭합니다.

제공 기능

카카오톡·문자 전송용 텍스트 복사
Excel(xlsx) 다운로드
PDF 다운로드
인쇄
⑦ 공지 & 쪽지

공지 작성에서 수업 변경, 휴강, 행사 안내 등을 등록합니다. 핀 고정 기능으로 중요 공지를 상단에 유지할 수 있습니다.

회원이 보낸 문의는 쪽지 수신함에서 확인합니다. 비회원도 쪽지를 보낼 수 있으며 연락처가 함께 표시됩니다.

⑧ QR 코드 활용

QR 코드 관리에서 단지별 QR 코드를 생성하고 PNG 파일로 다운로드합니다.

QR 코드를 스캔하면 해당 단지의 수업 예약 페이지로 바로 이동합니다. 엘리베이터, 커뮤니티 센터 입구 등 눈에 잘 띄는 곳에 부착하면 효과적입니다.

QR 코드 → 랜딩 페이지 → 회원가입 → 로그인 → 수업 예약 순서로 안내됩니다.
운영 중 문의사항이 있으시면 쪽지 보내기를 이용해 주세요.
